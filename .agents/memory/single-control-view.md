---
name: Single control view
description: The current product decision for control placement and responsive scope.
---

Use one canonical interface with operational controls arranged in horizontal rows along the bottom. Do not maintain a separate fold, narrow, mobile, or short-height control arrangement unless the user explicitly reopens that work.

**Why:** The user rejected both the right-side operational rail and a fold-specific alternate view. The immediate requirement is one view only.

**How to apply:** Preserve original control element identities and event wiring while keeping Context/Radio and Display/CCTV in the horizontal bottom deck. Treat responsive control reflow as separate future scope.
